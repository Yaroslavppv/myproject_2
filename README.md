## Классы
### Product - Класс для продуктов
#### Функции:
 - new_product(cls, product_dict: dict) - Добавление(обновление) нового продукта из словаря
 - price(self) - Отображение цены товара
 - price(self, new_price: float) - Изменение цены товара

### Category - Класс для категорий продуктов
 - products(self) - Отображение списка товаров в категории
 - add_product(self, product: Product) - Добавление нового продукта в категорию
