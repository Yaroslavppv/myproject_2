## Классы
### Product - Класс для продуктов
##### Функции:
 - new_product(cls, product_dict: dict) - Добавление(обновление) нового продукта из словаря
 - price(self) - Отображение цены товара
 - str(self) - Возвращает информацию о категории в строке
 - add(self, other: Product) - Сложение двух продукторв
 - price(self, new_price: float) - Изменение цены товара

#### Smartphone(Product) - Класс для смартфонов
#### LawnGrass(Product) - Класс для газонной травы


### Category - Класс для категорий продуктов
##### Функции:
 - products(self) - Отображение списка товаров в категории
 - str(self) - Возвращает информацию о категории в строке
 - add_product(self, product: Product) - Добавление нового продукта в категорию

### Order - Класс заказов
##### Функции:
 - add_product(self, product: Product) - Добавление продукта в заказ
 - add_quantity(self, quantity: int) -  Добавление кол-ва продуктов в заказ


### RangeCategory - Итератор, возвращающий поочередно продукты из категории
